# Studio mission release notes

Schema Baron now provides a compact local Studio for authoring SQLite-backed applications. Start with a blank project, build pages from Grid/Record/Search/Login forms, design and review schema changes, create reusable queries/reports, inspect application flow, and generate a readable independent TypeScript/Next.js application.

Visitor identity and access policies are separate from the Studio owner session. Generated applications support protected Record operations, constrained login return context, validation, referential deletion rules and exact decimal calculations. Preview shows the current draft; Live Page shows explicitly built generated output. Declared authored validators/actions/services/events survive regeneration; owned source conflicts stop before overwrite. Migration and source-promotion recovery preserve complete recoverable state and report actual committed outcomes.

Both Equipment Desk and an unrelated Publication Catalog have real visible-authoring, independent runtime, two-regeneration, data/source preservation and transport evidence. The readiness index records observed scope and limits, including native keyboard zoom, scale budgets and recovery/security injection results. New clean-install tooling removes developer-home and retained private-study dependencies and supplies the pinned test audit asset.

Supported observed platform is Linux x64/glibc with Node 24.22.1/npm 11.19.1, scripts denied. Current target has one SQLite connection, static routes, constrained HTML and synchronous Record extension points. Custom form/control CSS width/classes and form-level formatting, composite lookup widgets, protected query Search/navigation and exact-decimal Table Sort are not supported implicit features; their diagnostics remain visible. Mapped-identity include-data export is refused. Portable output excludes accounts/sessions/secrets; new deployment provisioning is explicit.

These notes prepare review on the mission feature branch. They do not announce a hosted release or deployment. Formal acceptance, consolidation, post-merge mission review, retrospective and a later draft PR must record their own actual outcomes.
