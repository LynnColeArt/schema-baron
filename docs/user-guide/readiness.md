## Readiness limits

No mandatory FR category is wholly absent from the observed implementation, but its support boundaries are real. The table records supported behavior and explicit refusals; it does not claim arbitrary CSS, routes, multiple connections, events, protected query navigation or composite lookup support. These limitations must be visible to the reviewer considering scope acceptance, rather than expanded in this documentation package.

The unused `@schema-baron/ui` scaffold reports NOT IMPLEMENTED. Python architectural gate coverage is **no_coverage / unverified** because `tests.architectural._gate_coverage` is unavailable. Local results are not hosted CI or production deployment evidence. Other-platform/native-source-build behavior, exhaustive security review, arbitrary crash combinations and cloud hosting remain unverified. Formal mission accept/consolidate/post-merge review/retrospective and later PR are separate workflow actions.
